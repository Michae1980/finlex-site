# 财税法规通 · FinLex

**面向会计、税务、审计与企业财务实务的结构化法规检索与关联阅读工具 — 模糊联想、一键查全貌、条文级精准定位，支持在线直达与离线安装。**

> 当前收录 **251** 份规范文档 · **5,786** 条正文条文 · **892** 组跨文档关联 · 纯静态 PWA 离线可用

## 为什么做这个工具？

在日常查准则、核对税会差异或编写审计底稿时，经常会遇到这些困扰：

- *「查收入准则时，2024 版应用指南、准则解释、财政部实施问答和官方案例散落在不同文件里，怎么一眼看全？」*
- *「只记得模糊概念（比如想查金融工具里的套期会计，或者习惯打简称 `CAS14 总额法`、`长投 权益法`），怎么快速定位到正确条款？」*
- *「连续查了三四份文件之后，想回看前几步读过的内容，甚至直接看看这两份法规之间有什么关联，能不能一步到位？」*

**财税法规通** 将会计准则、税法、审计准则与商法综合四大领域的公开规范整合进一个安静、清爽的双栏阅读工作台。无需注册，打开网页即可检索、对比、画图谱，也可以一键安装到桌面离线查阅。

## 核心玩法与功能

### 玩法一：模糊搜索与概念家族联想

顶部全局搜索框不仅支持法规标题、文号与全库 5,786 条正文的全文检索，还针对财税审检索习惯做了专项优化：

- **即时模糊联想（前 8 条）**：输入关键词时，搜索框下方实时弹出相关度排名前 8 的候选法规，并标注命中原因（标题匹配 / 相关准则 / 正文命中条数），支持鼠标点击或键盘 `↑` / `↓` + `Enter` 直达。
- **概念家族联动**：搜索宽泛主题时，自动带出同族核心准则（例如输入「金融工具」，会同步联想《金融工具确认和计量》《金融资产转移》《套期会计》《金融工具列报》及配套指南）。
- **多词空格组合与简称扩展**：支持空格分隔的多词 AND 检索，以及 35+ 高频财税审简称自动识别。

| 输入示例 | 自动识别与联想效果 |
| :--- | :--- |
| `金融工具` | 联想金融工具确认和计量、金融资产转移、**套期会计**、金融工具列报及实施问答 |
| `CAS14 总额法` | 自动扩展为「第14号 + 主要责任人」，直接定位收入准则及指南相关条款 |
| `长投 权益法` | 自动扩展为「长期股权投资 + 权益法」，高亮正文命中条文 |
| `解释 18` | 直达《企业会计准则解释第18号》及对应修订条款 |
| `企税 加计扣除` | 联动企业所得税法、实施条例与研发费用税前加计扣除政策 |
| `非标` | 联想非无保留意见审计准则（CSA 1502）与监管适用指引 |

### 玩法二：聚焦关联图谱与 L1–L5 依据分级

在工作区点击 **「🕸 聚焦图谱」**，即可查看任意法规的上下游依据关系；图谱上方提供可点击的 **L1–L5 分级胶囊** 与 **文件类别下拉框**（准则正文、应用指南、解释/问答、法律/行政法规、规章/规范性文件、实务案例/解读），一键滤除无关干扰。

| 依据层级 | 定位说明 | 典型示例 |
| :--- | :--- | :--- |
| **L1 核心落地配套** | 与主法规一一对应的官方落地细则与效力沿革 | 同号 2024 应用指南、财政部实施问答、国务院实施条例、审计问题解答 |
| **L2 正式修补与权威解答** | 对主法规进行补充修订或明确监管边界的正式文件 | 准则解释第 1–20 号、监管适用指引、司法解释、上位授权法 |
| **L3 条文级精准引用** | 正文中显式引用其他法规或具体条号的交叉依据 | 《收入》与《金融工具》《租赁》《合并财务报表》之间的条文引用 |
| **L4 跨域实务衔接** | 跨专业领域的高频实务对照桥梁 | 会—税差异（如收入确认 ↔ 增值税/企税）、会—审衔接（如存货 ↔ 存货监盘） |
| **L5 实务案例与官方解读** | 辅助理解实务落地的参考案例与官方说明（非规范依据） | 财政部官方准则应用案例汇编、典型实务案例 |
| **🏛 体系上位总纲** | 总论型准则与下位具体准则的架构统领关系（不占图谱连线） | 《企业会计准则——基本准则》统领 41 份具体准则；《鉴证业务基本准则》统领 47 份审计准则 |

### 玩法三：双栏专注阅读与条文级精准下沉

- **三种左侧视图协同**：支持「📋 卡片列表」「📑 台账表格」「🕸 聚焦图谱」随时切换；默认按财税审 **体系编号序** 排列，也可切换为关联热度、最新生效/发布日期或条文体量。
- **沉浸式长文本阅读**：左右分栏宽度可自由拖拽（双击分隔条还原），点击右上角 **「⤢ 专注阅读」** 可全屏阅读正文；支持文内二次检索高亮、条文目录快速跳转与一键复制标准引用（`《文件名》（文号）第X条`）。
- **条文级默认折叠关联**：单条法条右侧显示克制的 **`🔗 关联 N`** 按钮，默认折叠不干扰正文阅读，展开后可直接点击「定位」跳转到对应指南、实施问答、官方案例或关联税法条款；正文顶部还提供「仅看有关联条文」一键开关。

### 玩法四：浏览历史回溯与两两查关联

针对连续检索多份法规的实务场景，右侧阅读区顶部内置轻量历史导航栏：

- **`← 返回`**：按实际浏览顺序逐级回退（最多保留 40 步），悬停可预览上一份法规标题。
- **`🕒 最近浏览`**：自动去重记录最近查看过的 15 份法规，随时下拉回看。
- **`⇄ 查与上份关联`**：连续查阅 2 份及以上法规后出现，一键查询当前法规与上一份浏览法规之间的关联路径；若二者属于「总纲 ↔ 具体准则」关系，则直接给出架构统领说明。

## 使用方法

### 1. 在线访问与安装桌面版（推荐）
直接打开已发布的 GitHub Pages 网页地址即可使用；在 Chrome / Edge 等支持 PWA 的浏览器中，点击顶部「⬇ 安装」或地址栏右侧安装图标，可作为独立桌面/移动端应用离线查阅。

### 2. 本地离线使用
下载或克隆本仓库后，可通过以下任一方式在本地打开：

- **双击零配置打开**：直接用现代浏览器打开 `site/index.html`，无需任何依赖或服务器即可完成检索、阅读与图谱浏览。
- **本地静态服务预览**（体验完整 PWA 离线缓存与分享链接同步）：
  ```bash
  python3 -m http.server 8080 -d site
  ```
  随后在浏览器打开 `http://localhost:8080`。
