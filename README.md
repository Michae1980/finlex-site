# 财税法规通 · FinLex

**面向会计、税务、审计与企业财务实务的跨体系法规检索与关联阅读工作台 — 覆盖中国、国际与美国三大准则体系，支持模糊联想、平行对照、条文级精准定位与离线 PWA 安装。**

> 公开库内容持续更新，实时收录规模与最新法规动态请以网站首页展示为准。

## 涵盖体系一览（中国 + 国际 + 美国）

| 体系板块 | 核心涵盖范围与代表内容 |
| :--- | :--- |
| **中国体系（CN）** | 企业会计基本准则、具体准则正文、应用指南、准则解释、财政部实施问答与官方案例、小企业及可持续披露准则；中国审计准则（CSA）与问题解答；增值税法、企业所得税法、个人所得税法等核心税法；会计法、公司法、证券法等商法综合规范 |
| **国际体系（INTL）** | IFRS / IAS / IFRIC / SIC 会计准则卡片与段落号技术精要；ISSB 可持续披露（IFRS S1/S2）；IAASB 国际审计准则（ISA）；IESBA 职业道德守则；OECD 国际税收/支柱二规则；ESMA 执法案例与 G20 / COSO / FATF 治理内控与反洗钱框架 |
| **美国体系（US）** | FASB ASC 核心会计准则与段落号深度精要；PCAOB / AICPA 审计准则；IRC 联邦税法；SOX / SEC / FCPA 证券监管与公司治理框架 |

## 核心玩法与功能

### 玩法一：极简动态主页与三体系一键切换

首页提供居中的法规与政策动态滚动播报框（点击直达对应法规或官方链接）以及中国 / 国际 / 美国三体系快速入口，方便跨国财务报告、审计底稿与税会差异核对。

### 玩法二：模糊搜索、简称扩展与概念家族联想

顶部全局搜索框支持按体系/领域分片按需加载与多词空格 AND 检索，并内置高频财税审简称扩展与概念家族联动：

- **即时模糊联想**：输入关键词时实时弹出相关度最高的候选文档，标注命中原因（标题 / 相关准则 / 正文命中条数），支持 `↑` / `↓` + `Enter` 直达。
- **典型检索示例**：`CAS14 总额法`（扩展至收入准则主要责任人）、`长投 权益法`、`金融工具`（同步联动确认计量、转移、套期会计与列报）、`IFRS 15` / `ASC 606`、`企税 加计扣除`、`非标`（联动 CSA 1502）。

### 玩法三：聚焦关联图谱、L1–L5 依据分级与平行对照置底

点击 **「🕸 聚焦图谱」** 可查看任意法规的上下游依据网络，并按 **L1–L5 依据分级胶囊** 与 **文件类别** 精准过滤：

| 关联层级 / 区域 | 定位说明 |
| :--- | :--- |
| **L1 核心落地配套** | 与主法规一一对应的官方应用指南、实施问答、实施条例与审计问题解答 |
| **L2 正式修补与权威解答** | 准则解释、监管适用指引、司法解释与上位授权法 |
| **L3 条文级精准引用** | 正文中显式引用其他法规或具体条号的交叉依据 |
| **L4 跨域实务衔接** | 会—税差异、会—审衔接等跨专业实务桥梁 |
| **L5 实务案例与官方解读** | 财政部官方应用案例、ESMA 执法案例等参考资料（显式标为非规范依据） |
| **⇄ 平行对应准则（置底）** | 跨体系同位准则（如 `CAS 14 ↔ IFRS 15 ↔ ASC 606`）统一置于聚焦节点正下方，按 `CN → INTL → US` 排序并以双向虚线展示，避免误读为上下级从属 |
| **🏛 体系上位总纲** | 基本准则等总论型架构统领关系，在顶部提示而不占用图谱连线 |

### 玩法四：双栏专注阅读、条文级下沉与浏览历史

- **三视角协同**：左侧支持「📋 卡片列表」「📑 台账表格」「🕸 聚焦图谱」切换，支持按体系编号序、关联热度、最新日期或条文体量排序。
- **沉浸阅读与条文关联**：左右分栏可自由拖拽（双击还原），支持全屏专注阅读、文内高亮、目录跳转、一键复制标准引用；单条法条关联默认折叠，不干扰阅读。
- **浏览历史回溯**：详情区顶部内置逐级返回栈、最近浏览列表与一键查询与上份法规的关联路径。

## 本地运行、构建与方案 B（私用隔离）

- **直接离线使用**：双击用现代浏览器打开 `site/index.html`，零依赖零跨域报错即可检索、阅读与查看图谱。
- **本地静态服务预览（完整 PWA 离线缓存）**：
  ```bash
  python3 -m http.server 8080 -d site
  ```
- **构建与全量质检**（仅需 Python 3.9+，零第三方依赖）：
  ```bash
  python3 scripts/build_site.py && python3 scripts/validate.py
  ```
- **方案 B（本机私用官方 PDF 叠加）**：如需叠加本机受版权限制的官方手册 PDF，可运行 `python3 scripts/build_site.py --include-private`，产物隔离输出至 git-ignored 的 `site_private/`，绝不污染公开 `site/`。
