# 快速开始

## 检索结果怎么读

每条结果是一文一条：同一文档在结果中只出现最相关的一条，不刷屏。结果按问题域加权——查税务问题时法律、条例、规章优先；查会计问题时准则、解释、指南优先；案例权重最低，只作参考。

## 关联规定怎么分组

从一条规定点开「关联规定」，按五组呈现：

| 分组 | 含义 |
|------|------|
| 直接依据 | 该问题域内的权威规范（如税务问题的法律 → 条例 → 规章） |
| 关联规定 | 跨域或主题衔接的规范 |
| 官方解读 | 发布机关的解读文件 |
| 相关案例 | 案例参考，**非规范依据** |
| 效力沿革 | 现行文与被替代旧文的版本链 |

## 引用一条规定

按 [引用格式规范](/resources/citation) 格式引用，附官网原文链接，即可自行核对。
