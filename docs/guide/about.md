# 关于问财答税

**问财答税（代号 FinLex）** 为客户提供**可核对出处**的会计准则 / 税法法条 / 案例检索与联想解读；不做黑盒结论机。

## 产品一句话

为客户快速查到**有出处、有效力状态**的会计与税法依据，并给出**可回指原文**的白话解读与相关联想。

## 三个约定

1. **只保留最新有效文本**：被替代的旧文不进入检索集合；过渡期双版本并存时标明各自生效安排。
2. **元数据强制**：发布单位、发布日、生效日、文号、效力状态缺一不可；不可核实的标「待核实」，不编造日期与文号。
3. **无出处不输出**：解读中的主张必须能回指到具体条款；案例只作参考，不作规范依据。
